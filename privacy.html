Privacy Policy for Auto Refresher

Product: Auto Refresher (Chrome Extension) • Developer: Innova IT Hub • Effective Date: October 1, 2026
Privacy Commitment: Auto Refresher is built with a strict privacy-first architecture. We do NOT collect, store, sell, transmit, or monetize any user personal data, browsing history, form inputs, or keystrokes. All extension operations run 100% locally in your browser.

1. Information We Do Not Collect

Auto Refresher does not collect any personally identifiable information (PII) or telemetry. Specifically, we do NOT collect:

  • Personal identification information (names, email addresses, phone numbers, IP addresses).
  • Browsing history, search queries, or visited URL histories.
  • Form inputs, credentials, authentication tokens, passwords, or typed text.
  • External analytics, telemetry, crash reporting, or tracking cookies.

2. Data Stored Locally on Your Device

All settings and configuration options created by the user are stored strictly locally on your own computer using Chrome's native offline storage API (chrome.storage.local). This includes:

  • Refresh intervals, timers, and countdown durations.
  • Anti-bot random delay configurations.
  • Visual countdown timer display preferences.
  • Page monitor keywords and alert sound preferences.

This data never leaves your browser and is immediately deleted if you uninstall the extension or clear your browser storage.

3. Chrome Permissions & Why They Are Used

Auto Refresher requests only the minimal set of permissions necessary to deliver its core auto-refresh and tab management features:

  • storage: Used solely to save your refresh timer settings and preferences locally on your machine.
  • alarms: Used to schedule and trigger accurate periodic page reloads via the Chrome alarms engine without background drift.
  • contextMenus: Used to provide convenient right-click options (Pause for 5 mins, Pause for 15 mins, Resume, Stop) directly from any web page.
  • tabs: Used to identify and reload the specific browser tab where the user activated the auto-refresh timer.
  • notifications: Used exclusively to show local desktop alert banners when a user-configured keyword or condition is detected on a monitored page.
  • power: Used optionally to prevent the system from going to sleep while a critical auto-refresh timer is running (only when explicitly enabled by the user).
  • Host Permissions (<all_urls>): Required so that the extension can execute refresh commands and maintain scroll position across any website the user chooses to refresh.

4. Third-Party Sharing & External Servers

Auto Refresher communicates with zero external servers. We do not integrate any third-party analytics (e.g., Google Analytics, Mixpanel), tracking scripts, or ad networks. There are no remote API calls made by the extension during operation.

5. Zero Keylogging & Content Safety

Auto Refresher includes an input-safety detector that pauses reloads when you are actively typing in a form or input box. This detector only checks the active DOM element tag type (e.g., <input> or <textarea>) to avoid disrupting your typing. It never records, reads, or stores the keystrokes or text entered.

6. Changes to This Privacy Policy

We may update this Privacy Policy from time to time to reflect any potential updates in functionality or Chrome Web Store policy compliance. Any updates will be posted directly to this URL with an updated effective date.
